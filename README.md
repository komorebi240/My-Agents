# My Agents

Personal agent instructions and skills for Orbit.

- `CLAUDE.md`: engineering guidance.
- `AGENTS.md`: conventional entry point.
- `.claude/CLAUDE.md`: session and approval procedure.
- `.claude/skills.json`: inventory.
- `.claude/skills/`: maintained skill sources.
- `.gitmodules`: upstream UI and GSAP dependencies.

This repository is independent of the application. Restore these files into a local Orbit workspace when needed; Orbit ignores them. Documentation links resolve relative to that workspace.

Excluded: worktrees, locks, execution history, secrets, environment files and build outputs. Upstream UI and GSAP skills must retain their original submodule revisions.

Published independently from the Orbit application. Local workspace instructions stay ignored by the application repository.
